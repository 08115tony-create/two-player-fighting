# 拳魂對決・雙人格鬥 | Two-Player Fighting

六名擬真動漫格鬥家、六個對戰場景，每人三招加一個大招。
三種玩法：電腦對戰、雙人同機、P2P 線上邀請碼真人對戰。

## 放到 GitHub Pages 的步驟

1. 先把壓縮包解開，會得到資料夾 `two-player-fighting`。
2. 在 GitHub 建立一個新的 repository（例如取名 `two-player-fighting`）。
3. 把 `two-player-fighting` 資料夾**裡面的全部檔案**上傳到 repository 的根目錄：
   - 重點：`index.html` 必須直接在根目錄，不要多包一層資料夾。
   - 資料夾裡的 `.nojekyll` 也要一起上傳（GitHub 網頁上傳可能會漏掉隱藏檔，漏了也沒關係，不影響遊玩）。
   - GitHub 網頁上傳單次有檔案數量／大小限制；檔案太多上傳不完時，改用 GitHub Desktop 或 git 指令整包 push 上去最穩。
4. 上傳完成後，進 repository 的 **Settings → Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/(root)**，按 Save。
5. 等 1～3 分鐘，Pages 頁面會顯示公開網址，格式是：
   `https://<你的帳號>.github.io/<repository 名稱>/`
   誰拿到連結都能直接打開玩，不用登入。

之後要更新版本：把新版檔案同樣上傳覆蓋舊檔即可，網址不變。

## 玩法

- **電腦對戰**：3 種難度，選角後隨機對手。
- **雙人同機**：同一台裝置、同一副鍵盤。
- **線上真人對戰**：P2P 直連（WebRTC / PeerJS）。一人「建立房間」拿到 6 碼邀請碼，另一人輸入邀請碼加入，雙方選角、都按「準備開戰」就開打。
  - 房主必須保持頁面開著，房主關掉頁面房間就結束。
  - 兩邊都要開同一個 GitHub Pages 網址才能連；線上雙方必須使用同一個版本，新舊版混打會打不出傷害。
  - 線上對戰需要網路（連 PeerJS 訊號服務）；電腦對戰與雙人同機不需要。

## 操作

- P1：A/D 移動・W 跳躍・S 蹲下（兼格擋減傷）・F/G/H 三招・T 大招（氣滿 100%）
- P2（同機）：方向鍵 ←/→ 移動・↑ 跳躍・↓ 蹲下・J/K/L 三招・I 大招
- 手機／觸控裝置會自動顯示觸控按鈕。
- BGM 預設關閉，按右上角 BGM 開關才會播放；音效不受影響。

## 內容

- 6 位角色：颯、剛、巖、雪莉、雷藏、櫻，各 12 種動作姿勢（共 72 張影格）
- 血量：颯 1320／剛 1530／巖 1720／雪莉 1380／雷藏 1425／櫻 1350；巖攻擊 7、防禦 8
- 6 個場景：霓虹擂台、櫻月神社、極光冰宮、熔核火山、雷雲天台、落日遺跡，外加隨機場景
- 對戰計時 150 秒
- 大招演出：氣滿放招時招式名稱大字＋半身特寫＋時間暫緩，線上雙端同步
- 隨機選角：三種玩法選角都有「隨機選角」；點了隨機仍可改按其他角色改選，只有最後以隨機開戰時才在開戰那一刻揭曉抽到誰
- 線上修正：身體碰撞不穿身（最小間距 98）、跳躍可跳過對手換位、攻擊方判定命中只扣一次血、防卡頓快照處理
